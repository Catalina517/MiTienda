    Documentación de la aplicación

    Cómo está construida

    1. Extracción: pandas lee las hojas Clientes, Empleados, Facturas, Pedidos, Productos y Proveedores.
    2. Transformación: se calculan el valor de cada venta (cantidad × precio unitario), la ciudad a partir de la dirección y la dimensión tiempo.
    3. Carga: las 9 tablas del modelo estrella se crean en la base de datos.
    4. Consulta: el tablero lee los datos del DW con SQL (no del Excel).
    5. Seaborn: cada uno de los 10 gráficos de ventas se dibuja para las 16 combinaciones de filtros (4 formas de pago × 4 tipos de venta). Junto a cada imagen se guarda la posición de cada barra, punto o celda.
    6. JavaScript: los filtros cambian las imágenes y recalculan los indicadores; al pasar el mouse se muestra el valor del elemento señalado.

    Indicadores

    Ventas totales = suma de cantidad × precio unitario. Ticket promedio = ventas ÷ número de facturas. Los valores están en las unidades monetarias de la base.

    Cómo ejecutarla

    En Google Colab suba MiTiendaOnline.xls, pegue el script dashboard_mitienda.py y ejecútelo. Para usar PostgreSQL instale sqlalchemy psycopg2-binary, escriba sus credenciales en CONEXIONES y cambie MOTOR = "postgresql".
